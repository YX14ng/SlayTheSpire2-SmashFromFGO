# Fuentes de nomenclatura coreana y rusa

Esta localización distingue entre dos clases de texto:

- Los nombres canónicos de personajes, habilidades, clases, Noble Phantasms y objetos de Fate usan la nomenclatura publicada o consolidada para cada idioma.
- Las cartas, poderes y reliquias originales del mod que no tienen equivalente canónico se traducen de forma natural, manteniendo el significado y las variables de SimpleLoc.

## Coreano (`kor`)

La referencia primaria es la localización oficial coreana de Netmarble. El sitio oficial es dinámico y no siempre permite enlazar directamente cada ficha, por lo que se contrastaron sus términos con páginas coreanas que reproducen los nombres mostrados en el juego.
